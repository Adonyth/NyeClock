【重要】微信发 HTML 文件 → 对方 Safari 报「无法打开文件」的原因
--------------------------------------------------------------------------------
  Mac 版微信把文件放在自己的沙盒路径里。Safari 用 file:// 打开时没有权限读该路径
  （NSURLErrorDomain -3001）。这不是 tw_.html 损坏。

  正确做法：不要把「本地文件」当成分发方式。请把下面整个文件夹部署到 **HTTPS**，
  只把 **https://你的网址** 发给朋友（手机、电脑、Safari、Chrome 均可）。


本目录内容
--------------------------------------------------------------------------------
  index.html   — 由 tw_.html 复制（与 Downloads 里的 tw_.html 同步）
  manifest.json — Web 应用清单（「添加到主屏幕」更接近 App）
  netlify.toml — Netlify 可选配置


如何发布（任选其一）
--------------------------------------------------------------------------------
  1) Netlify Drop：https://app.netlify.com/drop — 把「nye-clock-web」文件夹拖进去
  2) Cloudflare Pages、Vercel、GitHub Pages：上传本文件夹，根目录即站点根

发布后请用 **https://...** 链接分享。需要联网（页面从 CDN 加载 Three.js 等脚本）。


本地修改流程
--------------------------------------------------------------------------------
  1. 只编辑 ~/Downloads/tw_.html
  2. 终端执行：  ./sync-nye-clock-web.sh
  3. 重新上传/部署 nye-clock-web 文件夹
