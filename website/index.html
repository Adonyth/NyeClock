If this landing page is served under a subpath (e.g. /website/), use the button above or set the app URL in your deployment (see DISTRIBUTION.md).

Install on macOS (DMG)

The desktop app is a small window that opens the live web app. Pick the installer that matches your Mac, then follow the steps below.

Download .dmg — Apple Silicon (M1/M2/M3) Download .dmg — Intel

  1. Download the .dmg file using the button for your Mac type. If a direct download does not start, open the latest release and choose NyeClock-…-arm64.dmg (Apple Silicon) or NyeClock-…-x64.dmg (Intel).
  2. Open the downloaded .dmg. A window opens showing Nye Clock.
  3. Drag Nye Clock into your Applications folder.
  4. Open Applications, double-click Nye Clock. The first launch may show a security prompt — if macOS says the app cannot be opened, go to System Settings → Privacy & Security and choose Open Anyway for Nye Clock (this is normal for apps that are not notarized).
  5. Sign in under My account → Cloud in the app if you use cloud sync.

Build the DMG yourself

Optional: build installers on a Mac from the repo (desktop/).

  • cd desktop && npm install && npm run dist:mac
  • Set NYE_CLOCK_APP_URL before building so the app opens your deployed site.
