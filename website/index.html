Install on macOS

Apple Silicon only (M1 / M2 / M3 and newer). Intel Macs: use Open web app above.

  1. Download the .dmg and open it.
  2. Drag Nye Clock into Applications.
  3. If blocked on first launch: System Settings → Privacy & Security → Open Anyway.
