Install on macOS

The desktop build is Apple Silicon only (M1 / M2 / M3 and newer). It opens the same live site as the web version. If you use an Intel Mac, use Open web app instead.

  1. Click Download for macOS. Your browser should save the .dmg file directly (no repository page).
  2. Open the .dmg, then drag Nye Clock into Applications.
  3. Launch from Applications. If macOS blocks the first open, use System Settings → Privacy & Security → Open Anyway.
  4. Optional: sign in under My account → Cloud for sync.
